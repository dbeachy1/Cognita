# Cognita 12.2.0 release notes

Cognita 12.2.0 reorganized the Admin interface into conventional desktop tabs.

## Included changes

- Connectors exposes connector setup, authorized clients, per-project access, and Workspace
  transfer as secondary tabs.
- Workspaces exposes runtime, policy, and Workspace-only connectors as secondary tabs.
- Canonical hash routes and independent ARIA tablists preserve selection across reloads, direct
  links, and browser history.
- Credential setup uses connection instructions and remains ephemeral after password
  reauthentication.

No connector, OAuth, Workspace, credential, authorization, storage, or MCP API contracts changed.
