# Security policy

## Supported versions

Security fixes are provided for the latest published Cognita release. Older releases should be
updated before reporting a problem that may already be fixed.

## Report a vulnerability

Please use **Report a vulnerability** on the [Cognita Security page](https://github.com/dbeachy1/Cognita/security/advisories)
to send a private report to the maintainers. Do not open a public issue for an unpatched
vulnerability. Include the affected version, a clear reproduction using synthetic data, and the
impact. Do not include passwords, tokens, private documents, or other people's data.

The maintainers will acknowledge the report privately, investigate it, and coordinate a fix and
disclosure through the GitHub security advisory. For a credential exposure, revoke the affected
credential immediately; the repository issue tracker is not a revocation channel.
